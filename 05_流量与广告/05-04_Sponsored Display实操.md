# 05-04 Sponsored Display 实操

- 版本：v1.0
- 最近更新：2026-08-27
- 维护人：运营负责人
- 证据等级：SD 定向类型/展示位置为 B 级官方；再营销策略为 D 级经验

## 1. 模块目的
Sponsored Display（SD）用于再营销、受众触达、竞品详情页防御与类目截流。解决「如何把看过没买的买家拉回来、如何在竞品详情页曝光自己」的问题。

## 2. 适用场景
- 再营销：触达看过你 Listing 但未购买的买家
- 竞品防御/截流：在竞品详情页展示自己的商品
- 类目触达：按品类/兴趣触达潜在买家
- **不适用**：精准关键词卡位（用 05-02 SP）、品牌旗舰店引流（用 05-03 SB）

## 3. 核心概念

### 3.1 SD 两种定向方式【B】
| 定向 | 说明 | 典型用途 |
|---|---|---|
| 受众定向（Audiences） | 按再营销（views remarketing）或兴趣/生活场景触达人群 | 拉回浏览未购、触达兴趣人群 |
| 商品定向（Product targeting） | 指定竞品 ASIN 或类目 | 竞品详情页截流、类目曝光 |

### 3.2 展示位置【B】
- 站内：商品详情页、搜索结果等。
- 站外：Amazon 合作的第三方网站与应用。
- 位置由系统匹配，卖家主要通过「定向」而非「选位置」控制。

### 3.3 再营销（Remarketing）【B/D】
- 定义：向看过你商品但未下单的买家再次展示【B 官方功能】。
- 运营逻辑：这类人群已表现出兴趣，转化概率相对高【D 经验】。
- 注意：再营销有受众量限制，若 Listing 流量小，可再营销人群规模也小（D 经验）。

## 4. 核心指标
- CTR / CVR / CPC / ACOS / TACOS：定义见 08-01 / 05-01。
- **触达频次与回访**：再营销人群被触达与回访情况（以后台可用数据为准）。
- **详情页位置表现**：商品定向在竞品详情页的 CTR 与 ACOS，判断「防御/截流」效果。

## 5. 决策树
- 如果 高流量但转化低 → 用再营销拉回浏览未购买家
- 如果 竞品截流严重 → 用商品定向投主要竞品 ASIN 做防御
- 如果 想类目拓量 → 商品定向投相关类目，观察 2 周
- 如果 SD 的 ACOS 高但带来回访/加购 → 用「回访转化」综合判断，不孤立看 ACOS
- 如果 再营销人群量极小 → 先做流量（SP/SB），再谈再营销（D 经验）

## 6. 标准操作流程
Step 1：进入 Seller Central → 广告 → 创建广告活动 → 选择 Sponsored Display。
Step 2：选择定向方式（受众定向 或 商品定向）。
Step 3：受众定向 → 选再营销（views remarketing）或兴趣受众；商品定向 → 选竞品 ASIN 或类目。
Step 4：设置每日预算与竞价。
Step 5：命名规范：如 `SD-<ASIN>-<定向>-<日期>`。
Step 6：保存并确认启用，记录初始参数。
Step 7：按周期导出数据，进入 05-11 优化循环。

## 7. 操作前检查
- 明确 SD 目标（再营销 / 防御 / 类目拓量）。
- 若做商品定向，竞品 ASIN 清单已按 02-04 整理。
- Listing 流量基础足够支撑再营销（流量太小再营销人群也小）。
- 预算可控（SD 站外展示与再营销成本需观察）。

## 8. 操作后检查
- 活动已启用且有曝光。
- 数据可归集到「受众定向 / 商品定向」。
- 再营销与商品定向的表现分开记录，不混在一起判断。
- 观察满 2 周再下结论。

## 9. 成功标准
- 再营销：回访/转化提升，ACOS 相对可控。
- 商品定向：在竞品详情页获得稳定曝光与点击，实现防御或截流。
- 综合用「增量转化 + TACOS」评估，不孤立用 ACOS（SD 位置与属性决定）。

## 10. 失败处理
- 无曝光 → 检查定向人群/ASIN/类目规模与竞价（10-03）。
- ACOS 高且无回访转化 → 收窄定向或停投该定向。
- 防御无效（竞品详情页无曝光）→ 检查竞品 ASIN 是否可定向、竞价是否足够。

## 11. 常见错误（新人高频）
1. 流量小就做再营销，人群量不足无效果。
2. 把 SD 当 SP 用，用纯 ACOS 考核。
3. 竞品 ASIN 选错（选到类目龙头，防御成本高效果差）。
4. 受众/商品定向数据混在一起，无法判断哪个有效。
5. 站外展示效果被误判为「垃圾流量」而不看转化窗口。

## 12. 风险
- 资金：SD 站外展示与再营销可能短期 ACOS 高，预算需上限。
- 决策：错误选择竞品 ASIN 导致高花费低转化。
- 合规：素材/落地承接需符合政策。

## 13. 实战案例
背景：某 Listing 有流量但转化偏低，用户多为「浏览未购」，希望提升转化。
数据（教学假设值）：月 Sessions 12,000，Unit Session % 8%（偏低），浏览未购人群较大。
判断：适合用再营销触达浏览未购买家。
决策：启动 SD 受众定向（再营销），预算设上限，观察 2 周。
操作：SD 再营销定向浏览过本 ASIN 的人群，配合详情页 A+ 与 Review 优化提升承接。
结果：再营销点击的转化率高于冷流量约 1.5 倍，整体 Unit Session % 升至 9.2%。
复盘：浏览未购人群是高意向流量，再营销能回收这部分流失；前提是 Listing 已有足够流量池。

## 16. 复盘方法
- 每日：花费快照。
- 每周：分定向（受众/商品）的 ACOS 与转化，收窄无效定向。
- 每月：SD 对整体增量转化的贡献，决定是否扩预算。
