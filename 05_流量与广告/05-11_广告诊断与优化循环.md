# 05-11 广告诊断与优化循环

- 版本：v1.0｜最近更新：2026-08-27｜维护人：运营负责人
- 证据等级：诊断方法为 D 级经验；异常急救见 10-03

## 1. 模块目的
建立「发现问题→定位原因→调整变量→等待观察→复盘」的完整循环，防止盲目调广告。

## 2. 适用场景
- ACOS/CPC/CTR/CVR 异常时
- 每周/每月广告复盘
- 广告目标未达成时；突发异常先走 10-03 急救

## 3. 核心概念
- 五步循环：发现问题 → 定位原因 → 调整变量 → 等待观察 → 复盘。
- 单一变量：一次只改一个变量（竞价/词/位/预算），否则无法归因【D】。
- 观察窗口：调整后至少 7 天（D），给足数据积累。

## 4. 核心指标
- 拆解链：ACOS = CPC / (CVR × 售价)，所以 ACOS 上升只可能是 CPC 升、CVR 降或售价降。
- CTR/CVR/CPC/曝光，见 08-01。

## 5. 决策树
- 如果 ACOS 上升 → 先拆 CPC 与 CVR：CPC 升→竞价/竞争；CVR 降→Listing/价格/Review
- 如果 CTR 降 → 主图/价格/广告位/相关性
- 如果 曝光降 → 预算/竞价/否定/库存/资质（10-03）
- 如果 有曝光无点击 → CTR 问题（主图/价格/相关）
- 如果 有点击无转化 → CVR 问题（Listing 承接）

## 6. 标准操作流程
Step 1：发现问题（ACOS 连续 7 天超盈亏平衡线）。
Step 2：定位原因（拆 CPC/CVR/CTR/曝光）。
Step 3：调整单一变量（如降竞价 或 换词 或 改溢价）。
Step 4：记录调整（变量、幅度、日期、原因）。
Step 5：等待观察 ≥7 天。
Step 6：复盘效果，无效则换下一个变量。

## 7. 操作前检查
- 数据周期足够（≥7 天均值）。
- 盈亏平衡 ACOS 已按 09-01 算好。
- 明确本次只改一个变量。

## 8. 操作后检查
- 调整已记录留痕。
- 观察期内不再改其他变量。
- 到期复盘。

## 9. 成功标准
- 每次调整有记录、有归因。
- ACOS 回到盈亏平衡线附近或目标区间。
- 能说清「是什么导致的、改了什么、结果如何」。

## 10. 失败处理
- 一个变量调整无效 → 换下一个变量，仍无效升级负责人。
- 连续多轮无效 → 查是否 Listing/产品根本性问题（04/06）。

## 11. 常见错误
1. 一次改多个变量，无法归因。
2. 调完 2 天就下结论。
3. ACOS 升直接砍预算/停广告，不拆原因。
4. 只看 ACOS 不看 TACOS（05-12）。

## 12. 风险
- 资金：错误操作放大亏损。
- 决策：归因错误导致反复折腾。

## 13. 实战案例
背景：某活动 ACOS 从 25% 升到 38%。
数据：CPC $1.1→$1.6（升），CVR 12%→11%（微降）。
判断：主因是 CPC 涨（竞争加剧），不是转化崩。
决策：降竞价 + 换长尾词，而非改 Listing。
操作：核心词降价 20%，补充长尾词。
结果：7 天后 CPC 回落 $1.3，ACOS 32%。
复盘：ACOS 拆解 CPC/CVR 是第一步，避免错改 Listing。

## 14. Checklist
- [ ] 确认问题（7 天数据）
- [ ] 拆 CPC/CVR/CTR/曝光
- [ ] 定位根因
- [ ] 调整单一变量
- [ ] 记录留痕
- [ ] 观察 ≥7 天
- [ ] 复盘

## 15. 数据记录模板
字段：日期|活动|问题|根因|调整变量|幅度|观察结果|是否有效|备注

## 16. 复盘方法
每周执行一轮循环；每月总结「哪些调整有效」，沉淀为团队经验（D）。
