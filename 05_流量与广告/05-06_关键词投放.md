# 05-06 关键词投放

- 版本：v1.0
- 最近更新：2026-08-27
- 维护人：运营负责人
- 证据等级：匹配类型为 B 级官方；搜索量为第三方 C 级估算；关键词分层策略为 D 级经验

## 1. 模块目的
解决「关键词从哪来、怎么分类、怎么分匹配类型投、怎么管理」的问题。关键词是 SP/SB 的投放核心，选错词或匹配错，广告费直接打水漂。

## 2. 适用场景
- 手动广告（SP/SB）关键词投放
- 自动广告「跑词 → 收割」流程
- 关键词库的分层管理与定期优化
- **不适用**：商品/类目定向（05-07）、否定词操作（05-10）

## 3. 核心概念

### 3.1 关键词来源（按可信度排序）
| 来源 | 说明 | 等级 |
|---|---|---|
| 自己广告的搜索词报告 | 真实买家的真实搜索词，最可信 | B |
| Brand Analytics 搜索词频率排名 | 品牌注册后的官方搜索数据 | B |
| 自动广告跑出的词 | 系统根据 Listing 匹配的词 | B |
| 竞品 Listing 反查 | 竞品标题/五点的高频词 | C/D |
| 第三方工具（Helium10 等）搜索量 | **估算值**，用于排序参考 | C |

### 3.2 关键词分类【D 经验】
| 类型 | 特征 | 投放策略 |
|---|---|---|
| 核心大词 | 搜索量大、竞争高、相关性强 | 精确/词组，打排名，预算高 |
| 长尾词 | 搜索量小、意图明确、竞争低 | 精确，控成本，转化高 |
| 品牌词 | 自身品牌词 | 精确防守，低 ACOS |
| 竞品词 | 竞品品牌/型号词 | 谨慎投放，看转化与合规 |

### 3.3 匹配类型选择【B 官方定义 + D 策略】
- 广泛（Broad）：拓词、跑量，需配合否定（05-10）。
- 词组（Phrase）：过渡，词序固定，前后可加词。
- 精确（Exact）：精准卡位、防守核心词。
- 常见路径：广泛跑出有效词 → 词组验证 → 精确收割（D 经验）。

### 3.4 核心原则：相关性 > 搜索量
- 搜索量高但相关性低的词，CTR/CVR 差，只会拉高 ACOS（D 经验）。
- 第三方搜索量是估算，不能作为唯一依据（C 级）。

## 4. 核心指标
- **单关键词 CTR / CVR / ACOS**：判断每个词值不值得投。
- **搜索量（估算）**：第三方工具，C 级，仅排序参考。
- **相关性**：词与商品的匹配程度，主观判断 + 搜索词报告验证。
- **关键词数量与花费集中度**：判断是否「长尾词太少、核心词烧穿」。

## 5. 决策树
- 如果 自动广告跑出高转化词 → 移入手动精确组，单独加价
- 如果 广泛匹配烧钱无转化 → 查搜索词报告 → 低相关词否定，核心词收窄
- 如果 核心词 ACOS 高但自然排名在升 → 保留并看 TACOS，不轻易砍（05-12）
- 如果 长尾词 ACOS 低且转化稳 → 扩更多长尾词，形成「长尾护城河」
- 如果 竞品词 ACOS 高且无转化 → 停竞品词，专注自身词

## 6. 标准操作流程
Step 1：建立关键词库（来源见 3.1），记录来源与证据等级。
Step 2：按 3.2 分类（核心/长尾/品牌/竞品）。
Step 3：在手动广告组中按匹配类型投放（广泛-拓词、精确-精准）。
Step 4：设置各关键词竞价（参考 05-08）。
Step 5：记录关键词台账（词、匹配、竞价、ASIN、目标）。
Step 6：每周导出搜索词报告，按 05-10 否定无效词。
Step 7：高转化词升级到精确组，低效词降价或否定，进入 05-11 循环。

## 7. 操作前检查
- 关键词来源已标注（官方报告 vs 第三方估算）。
- 词与 ASIN 的相关性已人工确认（不能只看搜索量）。
- 否定词清单已准备（05-10）。
- 每个词的目标明确（打排名 / 控成本 / 防守）。

## 8. 操作后检查
- 关键词台账与后台一致。
- 每个词的 CTR/CVR/ACOS 能单独导出。
- 广泛组已配套否定，避免无效词烧钱。
- 无「一个词多个匹配类型重复投放导致互抢」（除非有意测试）。

## 9. 成功标准
- 核心词自然排名上升（见 05-12）。
- 长尾词组 ACOS 低于核心词组，形成成本梯度。
- 关键词花费集中度高（头部 20% 词贡献大部分转化，D 经验）。

## 10. 失败处理
- 词无效（低相关）→ 否定或删除，看搜索词报告归因。
- 核心词竞争太贵 → 降竞价转词组/长尾，先做长尾再攻核心。
- 搜索量为 0 或极低 → 放弃该词，不浪费预算。

## 11. 常见错误（新人高频）
1. 只看第三方搜索量，不看相关性，投错词。
2. 广泛匹配不配否定，烧钱。
3. 一个词投多个匹配类型又互抢流量。
4. 核心词只投广泛，不设精确防守。
5. 品牌词不投，被竞品截流。

## 12. 风险
- 资金：低相关词烧穿预算。
- 合规：竞品词涉及品牌名，需注意政策边界（05-06 竞品词使用谨慎）。
- 决策：用估算搜索量做精确阈值决策导致误判。

## 13. 实战案例
背景：某 ASIN 自动广告跑出 200 个搜索词，需决定哪些移入手动。
数据（教学假设值）：其中 8 个词贡献 70% 转化，ACOS 25%；其余 192 个词花费 30% 但几乎无转化。
判断：8 个高转化词应升级为手动精确，其余低效词应否定。
决策：8 个词移入手动精确组并加价，192 个词中的低相关词加入否定清单。
操作：新建精确组投 8 个词；批量否定无转化词。
结果：精确组 ACOS 18%，整体广告效率提升，自然排名随核心词转化上升。
复盘：自动广告的价值是「跑词」，跑出的词要分级收割，而不是让自动组无限跑下去。
