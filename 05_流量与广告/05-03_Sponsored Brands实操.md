# 05-03 Sponsored Brands 实操

- 版本：v1.0
- 最近更新：2026-08-27
- 维护人：运营负责人
- 证据等级：SB 格式/资格/素材规范为 B 级官方；策略层面（品牌词防守等）为 D 级经验

## 1. 模块目的
Sponsored Brands（SB）用于品牌曝光、品牌旗舰店引流、品牌词防守。解决「品牌认知从哪来、品牌流量怎么沉淀」的问题，与 SP 打单品形成分工。

## 2. 适用场景
- 已做品牌注册（Brand Registry）后使用
- 防守自身品牌词，防止被竞品抢走品牌流量
- 多 ASIN / 品牌旗舰店集中曝光
- 新品系列上市的品牌造势
- **不适用**：单品精准转化（用 05-02 SP）、再营销（用 05-04 SD）

## 3. 核心概念

### 3.1 SB 三种广告格式【B】
| 格式 | 展示形式 | 典型用途 |
|---|---|---|
| 商品集（Product Collection） | 品牌 Logo + 标题 + 多张商品图 | 多品展示、引流旗舰店 |
| 品牌旗舰店焦点（Store Spotlight） | 引导至旗舰店多个子页面 | 沉淀品牌流量 |
| 视频（Video） | 自动播放的品牌视频 | 品牌故事、高注意力曝光 |

### 3.2 投放资格【B，需定期验证】
- 通常需要品牌注册（Brand Registry）；具体资格以 Seller Central 广告后台当前提示为准。
- 素材要求：品牌 Logo、标题、图片/视频尺寸与文案均有官方规范，创建时以后台校验为准。

### 3.3 投放方式【B】
- 关键词投放：品牌词、类目大词、竞品词（策略见 05-06）。
- 商品投放：定向竞品 ASIN / 类目（见 05-07）。

### 3.4 品牌词防守【D 经验】
- 自身品牌词是「高意向流量」，转化高、成本低，必须防守。
- 若竞品投了你的品牌词，你应投自己的品牌词 + 在详情页做好承接，降低流失。

## 4. 核心指标
- CTR / CVR / CPC / ACOS / TACOS：定义见 08-01 / 05-01。
- **品牌旗舰店访问量**：SB 带来的旗舰店点击/访问，衡量「品牌流量沉淀」。
- **品牌搜索量 / 品牌词搜索趋势**：Brand Analytics 的搜索词频率排名，衡量品牌认知增长。
- **新客 vs 复购**：Brand Analytics 市场篮子数据，衡量品牌人群扩张。

## 5. 决策树
- 如果 品牌词被竞品抢占 → 立即投自身品牌词（精准）并评估详情页承接 → 防守
- 如果 品牌旗舰店访问低 → 用 Store Spotlight 格式引流旗舰店
- 如果 品牌认知弱、新品系列上市 → 用视频格式做品牌曝光
- 如果 品牌词 ACOS 高 → 查是否被竞品抬价、是否自身详情页转化差（见 05-11）
- 如果 多 ASIN 需要统一曝光 → 商品集格式聚合展示

## 6. 标准操作流程
Step 1：确认已做品牌注册，进入 Seller Central → 广告 → 创建广告活动 → 选择 Sponsored Brands。
Step 2：选择格式（商品集 / 旗舰店焦点 / 视频）。
Step 3：上传品牌 Logo、撰写标题、选商品或指定旗舰店页面、上传视频（如视频格式）。
Step 4：设置投放（关键词 或 商品/类目）与匹配类型。
Step 5：设置每日预算、竞价。
Step 6：命名规范：如 `SB-<品牌/系列>-<目标>-<日期>`。
Step 7：保存并确认活动启用，记录初始参数。
Step 8：按周期导出数据，进入 05-11 优化循环。

## 7. 操作前检查
- 品牌注册已生效（否则无法创建 SB）。
- 素材符合官方规范（Logo/标题/图片/视频，创建时后台会校验）。
- 旗舰店已搭建（Store Spotlight 需要旗舰店页面）。
- 品牌词/类目词已研究清楚（02-03）。
- 预算与 SB 的曝光属性匹配（SB 偏品牌曝光，不能只按 ACOS 考核，见 9 节）。

## 8. 操作后检查
- 活动已启用且有曝光（无曝光进 10-03）。
- 素材审核通过（未通过则按提示修改）。
- 数据可归集到格式/投放目标。
- 记录品牌旗舰店访问与品牌词搜索趋势基线。

## 9. 成功标准
- 品牌词防守到位：自身品牌词的广告位占据率高（D 经验）。
- 品牌旗舰店访问量随投放增长。
- 品牌词自然搜索趋势上升（Brand Analytics）。
- SB 整体用「TACOS + 品牌资产增长」综合考核，不孤立用 ACOS（D 经验，SB 曝光属性强）。

## 10. 失败处理
- 素材审核不过 → 按官方提示修改图片/文案，不重复提交同版。
- 无曝光/无点击 → 进 10-03 排查。
- 品牌词 ACOS 高 → 查竞品抬价与详情页转化（05-11），必要时降低竞价但保持防守存在。

## 11. 常见错误（新人高频）
1. 用 ACOS 单独考核 SB，忽视品牌曝光与旗舰店价值，误砍品牌广告。
2. 品牌词不防守，被竞品截流。
3. 素材不达规范反复提交被拒。
4. 标题写成促销语，而不是品牌主张/价值点。
5. 商品集塞入无关 ASIN，稀释品牌调性。

## 12. 风险
- 合规：素材（Logo/图片/视频/文案）违规风险，审核不通过或下架。
- 资金：品牌曝光类广告短期 ACOS 偏高，预算需设上限。
- 决策：只按 ACOS 考核会误判品牌广告价值。

## 13. 实战案例
背景：某品牌发现自身品牌词搜索广告位被竞品占据，品牌词转化率下降。
数据（教学假设值）：品牌词月搜索量 8,000，品牌词广告位竞品占比约 40%，自身品牌词转化率从 18% 降到 14%。
判断：品牌词是高意向流量，被竞品截流会直接损失转化与品牌认知。
决策：启动 SB 商品集 + SP 精准投放自身品牌词，防守品牌词顶部广告位。
操作：SB 商品集展示品牌旗舰店，SP 精确投品牌词并适度加价卡位；同时检查详情页 Review 与 A+ 承接。
结果：4 周后品牌词广告位自身占比回到 70%+，品牌词转化率回升到 17%。
复盘：品牌词防守是「低 ACOS 高转化」的必守阵地，属于品牌资产保护，不能按普通词成本逻辑评估。
