# 运营工作日志模板（每日/每周）

- 说明：老板/负责人通过本日志知道「运营今天做了什么动作」，不是只看数据。

## 每日工作日志（下班前 5 分钟填）
| 字段 | 填写说明 |
|---|---|
| 日期 | YYYY-MM-DD |
| 今日销量/异常 | 总销量 vs 7 日均值，有无异常 |
| 广告动作 | 今天调了什么广告（竞价/预算/否定/词），为什么 |
| Listing 动作 | 改了什么（标题/图/价/五点），为什么 |
| 库存动作 | 有无下单/发货/催入仓 |
| 客服/Review 动作 | 处理了什么差评/QA/退货 |
| 明日计划 | 明天要做什么 |
| 需升级事项 | 有无需要负责人拍板的事 |

## 每周工作日志（周五填）
| 字段 | 填写说明 |
|---|---|
| 本周核心数据 | 销量/ACOS/TACOS/库存覆盖 |
| 本周广告复盘结论 | 否定了哪些词、收割了哪些词 |
| 竞品变化 | 竞品价格/评论/排名有无突变 |
| 下周计划 | 下周广告/库存/Listing 动作 |
