## 3. 方法论结论（写入后续所有 SOP 的规则）
1. 精确费率/阈值表是 **login-gated**，无法用公开网页完全替代。
2. 因此 SOP 正文必须写成「进入 Seller Central → 对应费用/绩效页 → 读取当前值 → 记录」，并附「需定期验证」，而不是抄第三方博客的固定数值。
3. 第三方博客（Helium10 / feedvisor / credilinq 等）一律为 C 级，只用于排序参考，禁止作为阈值决策依据。
4. 同一指标出现多个第三方数值时，必须并列 + 标「待验证」，不得选一个写死。
