# 09-01 利润模型与口径

- 版本：v1.0
- 最近更新：2026-08-27
- 维护人：运营负责人
- 证据等级：见各节标注；费率类数值一律以 Seller Central 当前值为准

## 1. 模块目的
解决「到底赚不赚钱、赚多少、按什么口径算」的问题。统一全团队利润口径，避免选品、广告、库存、清库决策各自用不同的利润锚点导致误判。

## 2. 适用场景
- 选品利润测算（调用 02-06）
- 广告 ACOS / TACOS 盈亏平衡判断（调用 05）
- 定价与折扣决策（调用 06-01）
- 清库存 / 停售决策（调用 07-05 / 03-08）
- 月度 / 季度利润复盘（调用 11-03）
- **不适用**：现金流预测（用 09-04）、税务申报（用 09-05）

## 3. 核心概念

### 3.1 费用项（公式里必须逐项列出，禁止合并成「杂费」）
| 费用项 | 说明 | 证据等级 |
|---|---|---|
| 售价（Total Sales） | 成交价；美国站各州税由 Amazon 代收，通常不计入卖家收入，口径需按站点确认 | B，需定期验证 |
| Referral Fee（佣金） | 按类目百分比 + 每件最低佣金 | A/B，精确值需登录 Seller Central 费用页核实 |
| FBA 配送费 | 按尺寸/重量分档；2026-04-17 起另有燃油/物流附加费 | A/B，需登录核实 + 定期验证 |
| 仓储费 | 月度仓储费 + 长期仓储费（超龄库存） | A，需定期验证 |
| 广告费 | Amazon Ads 花费（SP/SB/SD 合计） | B |
| Coupon / Promotion / Deal 费 | 券面值 + 手续费 + Deal 报名费 | A/B，需定期验证 |
| 退货损失 | 退款 + 退货处理费 - 可回收佣金/残值 | B + D 经验口径 |
| 售后损失 | A-to-Z 索赔、赔付、缺陷导致的额外成本 | B + D |
| 头程物流 | 从供应商/国内仓到 FBA 仓的运费、关税、头程杂费 | D，按公司分摊方式定 |
| 产品成本（COGS） | 采购价 + 包装 + 贴标等，是否含头程由公司口径决定 | D，团队统一 |
| 固定成本 | 工资、房租、软件工具、样品等，是否分摊到 SKU 由公司口径决定 | D，团队统一 |

### 3.2 四层利润口径（全库唯一标准，其余模块必须引用本口径）
1. **毛利（Gross Profit）** = 售价 − 佣金 − FBA 配送费 − 产品成本 − 头程物流
2. **贡献利润 / 边际利润（Contribution Margin）** = 毛利 − 广告费 − Coupon/Promotion/Deal − 退货损失 − 售后损失
3. **运营利润（Operating Profit）** = 贡献利润 − 仓储费 − 固定成本分摊
4. **净利润（Net Profit）** = 运营利润 − 税费 − 其他非经营性收支

### 3.3 为什么不同公司口径不同（必须理解，不能照抄）
- 头程物流：计入「产品成本」还是「单列」，直接影响毛利率高低。
- 广告费：放在毛利层（当获客成本）还是贡献层，影响「产品本身是否值得做」的判断。
- 固定成本：是否按 SKU/销量分摊，影响单品净利润。
- 退货：是否含弃置费、是否按残值回冲，影响退货损失大小。
- 结论：本库统一采用 3.2 口径，并在 C01 计算器中写死，团队内不得混用。

## 4. 核心指标

### 4.1 毛利率
- 定义：毛利 / 售价
- 公式：(售价 − 佣金 − FBA费 − 成本 − 头程) / 售价
- 数据来源：付款报告 + 自建成本表
- 意义：产品「卖一件本身」的赚钱能力，不含获客与履约损耗
- 正常变化逻辑：随采购价、头程、费率变化；涨价/降本时上升
- 异常表现：毛利率为正但净利为负 → 获客或履约成本过高（见 4.4）
- 局限性：不含广告/退货，不能单独作为是否放量的依据

### 4.2 贡献利润率
- 定义：贡献利润 / 售价
- 公式：(毛利 − 广告 − 促销 − 退货 − 售后) / 售价
- 数据来源：付款报告 + 广告后台 + 退货报告
- 意义：扣除获客与售后后的真实可支配利润，是最重要的「产品健康度」指标
- 正常变化逻辑：广告效率提升、退货率下降时上升
- 异常表现：毛利率高但贡献利润率为负 → 广告 ACOS 或退货率失控（见 05-11 / 08-05）
- 局限性：未扣仓储与固定成本，不能等同最终盈利

### 4.3 单位贡献利润（$/件）
- 定义：贡献利润 / 销量
- 公式：见 3.2 第 2 层 / 件数
- 数据来源：同上
- 意义：判断「每多卖一件值不值」，用于放量与清库决策
- 正常变化逻辑：随规模与议价上升
- 异常表现：为负但仍在放量 → 停，查根因
- 局限性：受退货口径影响大

### 4.4 ACOS 盈亏平衡点
- 定义：广告花费 / 广告销售额 的最大可承受值（超过则广告边际亏损）
- 公式：盈亏平衡 ACOS = (售价 − 佣金 − FBA费 − 成本 − 头程 − 退货损失) / 售价
- 数据来源：见 05-08 / 05-12，本模块提供分子口径
- 意义：广告优化的「停止线」，不是目标值而是上限
- 正常变化逻辑：费率/成本变化时同步重算
- 异常表现：实际 ACOS 长期高于盈亏平衡点 → 广告亏损（见 10-03）
- 局限性：未考虑广告带来的自然排名增益（需结合 TACOS，见 05-12）

### 4.5 净利润率
- 定义：净利润 / 售价
- 公式：见 3.2 第 4 层 / 售价
- 数据来源：付款报告 + 成本表 + 费用分摊
- 意义：公司层面的最终盈利水平
- 正常变化逻辑：随规模摊薄固定成本而上升
- 异常表现：贡献利润为正但净利为负 → 固定成本或仓储费过高
- 局限性：固定成本分摊方式影响可比性

### 4.6 目标利润率（团队基准）
- 定义：团队自定的毛利/贡献/净利目标线
- 说明：**无行业通用标准，禁止引用第三方「必须 30% 毛利」类说法**
- 数据来源：团队历史数据回测（D 级）
- 使用：作为 9 节成功标准的判断线，非平台规则

## 5. 决策树
- 如果 毛利 < 0 → 检查 定价是否过低 / 佣金与 FBA 费配置是否错误 / 成本是否上涨 → 异常则执行 10-02
- 如果 毛利 > 0 但 贡献利润 < 0 → 检查 广告 ACOS 是否 > 盈亏平衡点 / 退货率是否异常 → 是则执行 05-11 / 10-02
- 如果 贡献利润 > 0 但 净利润 < 0 → 检查 仓储费与固定成本分摊 → 判断 SKU 是否值得保留（07-05）
- 如果 全部为正 → 进入 4.6 目标线对比，决定是否放量（03-09）

## 6. 标准操作流程
Step 1：进入 Seller Central → 付款（Payments）→ 结算报告 / 交易视图，选择周期（自然月）。
Step 2：导出交易明细，按 ASIN / SKU 归集：售价、佣金、FBA 配送费、退款。
Step 3：进入 Amazon Ads Console，导出同周期广告花费，按 ASIN 归集。
Step 4：打开自建利润计算器（C01），填入：销量、售价、佣金、FBA 费、产品成本、头程、广告、Coupon/Deal、退货量/损失、仓储费、固定分摊。
Step 5：计算毛利 → 贡献利润 → 运营利润 → 净利润 四层。
Step 6：与 4.6 目标线对比，标记达标/未达标 SKU。
Step 7：未达标 SKU 进入 08-06 利润诊断树定位根因，并记录。

## 7. 操作前检查
- 汇率已锁定（跨站点结算）。
- 结算周期与自然月口径一致（月末未结算订单是否计入）。
- 退款/退货归属到正确月份。
- 佣金/FBA 费率取的是 Seller Central 当前值（非历史值）。
- 广告花费周期与销售周期对齐（归因错位会误导，见 11 条）。

## 8. 操作后检查
- 四层利润均可计算且无异常负值。
- 广告花费与广告后台对账一致。
- 退货损失与退货报告对账一致。
- 总回款（付款报告）与四层计算可解释（差异来自固定成本/税）。
- 利润表金额单位、币种一致。

## 9. 成功标准
- 各 SKU 四层利润均能按月稳定产出，且对账差异 < 团队目标线（D 级自定）。
- 毛利率 / 贡献利润率 / 净利润率达到 4.6 目标线（D 级）。
- 每月复盘能明确列出「赚钱/亏钱/临界」三类 SKU，且根因清楚。

## 10. 失败处理
- 对不上账 → 逐项比对付款报告与计算器，定位漏项（最常见：漏仓储费、漏退货、漏 Deal 费）。
- 利润持续不达标 → 升级给负责人，用 08-06 利润诊断树定位，必要时决策降价清库或停售。
- 单月数据缺失 → 用次月补录并标记，禁止凭空估算后不标注。

## 11. 常见错误（新人高频）
1. 漏算退货损失与退货处理费。
2. 漏算仓储费（尤其超龄库存长期仓储费）。
3. 漏算 Coupon 手续费 / Deal 报名费。
4. 广告归因错位：用当月广告费对比当月全部销售，忽略广告带来的滞后转化。
5. 用「售价」而非「回款」当收入锚点。
6. 口径混用：有的 SKU 含头程、有的不含。
7. 引用第三方「必须 XX% 毛利」当硬标准。

## 12. 风险
- 资金：利润虚高导致盲目补货/放量，占用现金流。
- 库存：利润口径错误导致错误清库或错误囤货。
- 决策：单品净利润为负仍被「高毛利」误导继续投放广告。
- 合规/账户：本模块本身无直接合规风险，税务风险在 09-05。

## 13. 实战案例
背景：某厨房小工具 SKU，售价 $19.99，目标判断是否继续投放广告、是否补货。
数据（单月，教学假设值，非官方费率）：
- 销量 500 件；售价 $19.99；佣金 15% = $3.00/件；FBA 配送费 $5.20/件
- 产品成本 $4.00/件（含包装）；头程 $0.60/件；广告总花费 $1,600（$3.20/件）
- Coupon 5%（约 $1.00/件）；退货率 6%（退货损失约 $1.30/件）；仓储费 $0.50/件；固定分摊 $0.30/件
判断：
- 毛利/件 = 19.99 − 3.00 − 5.20 − 4.00 − 0.60 = $7.19 → 毛利率 36%（看似健康）
- 贡献利润/件 = 7.19 − 3.20 − 1.00 − 1.30 = $1.69 → 贡献利润率 8.5%
- 运营利润/件 = 1.69 − 0.50 − 0.30 = $0.89 → 净利率约 4.5%
决策：毛利率 36% 不能说明问题，贡献利润仅 8.5%，广告（$3.20）与退货（$1.30）是主要吞噬项。先不停止广告，但进入 05-11 优化 ACOS（目标降到盈亏平衡点以下），并排查退货原因（06-04）。
操作：降低低效关键词竞价、否定无效搜索词；针对退货主因改进包装/描述。
结果（次月）：ACOS 从 35% 降到 26%，退货率从 6% 降到 4.5%，贡献利润率回升到 13%。
复盘：利润诊断必须先看「贡献利润层」，不能只看毛利；广告与退货是利润最大变量。

## 16. 复盘方法
- 每日：广告花费 vs 销售快照（异常即时发现）。
- 每周：贡献利润率趋势，标记连续 2 周恶化的 SKU。
- 每月：全四层利润核算 + 对账 + 输出「赚钱/亏钱/临界」清单，驱动下月预算与清库决策。

## 18. 补录：易漏成本项（反向测试 G-C 修复）
除 3.1 已列费用外，利润模型还必须包含以下 6 项，否则利润虚高：
1. 收款/提现手续费（Payoneer/PingPong 等，按回款比例）
2. 汇损（跨币种结算汇率差）
3. 认证费（FDA/CE/UL/CPC 等合规认证，按件摊销）
4. 软件订阅费（Helium10 等工具，可归固定成本但必须单列）
5. 移除/弃置费（清库存时）
6. 样品/打样费（新品开发期）
