# 02-07 选品评审流程

- 版本：v1.0｜最近更新：2026-08-27｜维护人：运营负责人
- 证据等级：评审流程为 D 级团队机制

## 1. 模块目的
把选品决策做成「有证据、有记录、有责任人」的评审会，降低单人拍脑袋风险。

## 2. 适用场景
- 候选品进入立项前
- 阶段性选品评审会

## 3. 核心概念
- 评审材料：市场（02-01）、类目（02-02）、关键词（02-03）、竞品（02-04）、评分（02-05）、利润（02-06）。
- 评审角色：提交人、评审人、负责人。
- 结论：通过 / 驳回 / 补充材料再审。

## 4. 核心指标
- 评审通过率、驳回原因分布。
- 从评审到上线的命中率（后验）。

## 5. 决策树
- 如果 材料不全 → 驳回补材料
- 如果 有否决项 → 直接驳回
- 如果 综合分与利润均达标 → 通过立项
- 如果 临界 → 负责人拍板 + 记录

## 6. 标准操作流程
Step 1：提交人打包 02-01~02-06 材料与评分表。
Step 2：评审人按清单逐项核对。
Step 3：记录评审意见与结论。
Step 4：通过 → 立项转 03；驳回 → 写明原因。
Step 5：归档评审记录。

## 7. 操作前检查
- 材料齐全且数据标等级。

## 8. 操作后检查
- 结论与原因记录清楚。

## 9. 成功标准
- 每次选品有评审记录可追溯。

## 10. 失败处理
- 材料不足 → 补充再审。

## 11. 常见错误
1. 评审流于形式。
2. 无否决项检查。
3. 结论不记录。

## 12. 风险
- 资金：跳过评审的冲动选品。

## 13. 实战案例
背景：某候选品被一人力荐。
数据：评审发现合规有隐患（否决项）。
决策：驳回。
复盘：评审的否决项机制避免了合规风险。

## 14. Checklist
- [ ] 材料打包
- [ ] 逐项核对
- [ ] 查否决项
- [ ] 记录结论
- [ ] 归档

## 15. 数据记录模板
字段：候选品|提交人|评审日期|材料完整性|否决项|综合分|利润|结论|原因

## 16. 复盘方法
季度复盘命中率。
