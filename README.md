# Amazon 全流程运营 SOP 知识库

> 一套**可执行、可验证、可长期维护**的 Amazon 跨境电商运营操作系统。
> 不是经验分享文章合集，而是带**证据等级**、带**决策树**、带**检查清单**、带**计算器**的作战手册。

## 这是什么

一套覆盖 Amazon 卖家**全生命周期**的运营 SOP 知识库，共 96 份 Markdown 文档 + 3 个 Excel 计算器：

- 从**市场调研 → 选品 → 产品开发 → 供应链 → Listing → 广告 → 转化 → 库存 → 利润 → 风控**的完整主链路
- 每一份 SOP 强制采用**统一 17 节结构**（目的 / 场景 / 概念 / 指标 / 决策树 / 标准流程 / 操作前检查 / 操作后检查 / 成功标准 / 失败处理 / 常见错误 / 风险 / 案例 / Checklist / 数据模板 / 复盘 / 关联模块）
- 每一个关键事实强制标注**来源与证据等级**，并区分「官方规则」和「运营经验」

### 这不是什么

- ❌ 不是 Amazon 官方文档，与 Amazon 无任何隶属或授权关系
- ❌ 不承诺任何经营结果，不构成投资、法律或税务建议
- ❌ 费率、阈值、政策等时效性内容**必须**以上线时 Seller Central 的当前值为准

## 核心差异：五级证据等级

大多数运营资料的问题是把「我的经验」写成了「平台规则」。本知识库用强制标注把两者分开：

| 等级 | 定义 | 典型来源 | 使用要求 |
|---|---|---|---|
| **A** | Amazon 官方规则 | Seller Central 政策、服务条款、费率表 | 附官方链接 + 访问日期 +「需定期验证」 |
| **B** | Amazon 官方资料/培训 | Seller University、Amazon Ads 官方文档 | 附来源 + 访问日期 |
| **C** | 行业公开资料 | 第三方工具白皮书、行业报告 | 注明发布方 + 时间 |
| **D** | 成熟运营者经验 | 多次验证但无官方依据 | 标注「经验值，非硬性标准」 |
| **E** | AI 推理/假设 | 逻辑推导、待验证想法 | 仅作假设，禁止作为决策依据 |

**红线：禁止把 D/E 写成 A/B。** 全文规则见 [`00_总纲/00-02_证据等级与真实性规范.md`](00_总纲/00-02_证据等级与真实性规范.md)。

## 内容结构

```
00_总纲                 9 份   知识库怎么用、怎么维护、什么是可信
01_平台规则与账户       7 份   合规边界：什么能做、什么不能做
02_市场与选品           7 份   卖什么、为什么卖、能不能赚
03_产品开发与供应链     9 份   产品怎么做出来、怎么送到仓
04_Listing与内容        7 份   怎么被搜索到、被点击
05_流量与广告          14 份   流量从哪来、怎么买、怎么优化
06_转化与客户体验       5 份   流量怎么变订单、口碑怎么维护
07_库存与物流           6 份   不断货、不积压
08_数据与诊断           7 份   数据怎么看、问题怎么定位
09_利润与财务           5 份   到底赚不赚钱、赚多少
10_风控与异常           6 份   出事了怎么办
11_运营节奏与复盘       5 份   每天/周/月/季做什么
12_团队与培训           5 份   新人怎么带、岗位怎么分
99_支撑资产             —      通用案例手册、模板、资料卡、计算器
```

**五层架构**

```
L4 管理层        运营节奏与复盘 │ 团队与培训
L3 横向支撑层    数据与诊断     │ 风控与异常
L2 业务主链路    市场→选品→产品→供应链→Listing→广告→转化→库存→利润
L1 合规边界层    平台规则与账户（一切操作的红线）
L0 底座层        证据等级·术语表·数据来源·维护规范
```

## 配套 Excel 计算器

位于 [`99_支撑资产/计算器/`](99_支撑资产/计算器/)，全部为**真实公式**（不是死数值），黄色格为输入、绿色格为自动计算：

| 文件 | 输入 | 输出 |
|---|---|---|
| **C01_利润计算器.xlsx** | 21 项费用/收入输入 | 四层利润（毛利 → 贡献利润 → 运营利润 → 净利润）+ 盈亏平衡 ACOS + 盈亏判断 |
| **C03_库存补货计算器.xlsx** | 日均销量、生产/运输/入仓时间、安全库存、在途 | Lead Time、补货点、当前覆盖天数、预计断货日期、建议补货量、断货风险等级 |
| **C04_广告ACOS_TACOS计算器.xlsx** | 花费、广告销售、自然销售、售价与各项成本 | ACOS、ROAS、TACOS、广告销售占比、盈亏平衡 ACOS、是否超盈亏线 |

> 打开后默认显示一组教学示例值，改黄色单元格即自动重算。所有费率均标注「需登录 Seller Central 核实」。

## 快速开始

```bash
git clone <this-repo>
cd amazon-operations-sop
```

- **只想读**：直接看 [`00_总纲/00-08_使用指南与交付说明.md`](00_总纲/00-08_使用指南与交付说明.md)，或下载 Releases 里的完整 PDF（含封面、目录、全书排版）。
- **想用模板**：看 [`99_支撑资产/模板/`](99_支撑资产/模板/)。
- **想改内容**：先读 [`CONTRIBUTING.md`](CONTRIBUTING.md)，再读 [`00_总纲/00-01_知识库使用说明与维护规范.md`](00_总纲/00-01_知识库使用说明与维护规范.md)。

### 从 Markdown 重建 PDF

```bash
python 99_支撑资产/md2pdf.py
```

### 重建 Excel 计算器

```bash
python 99_支撑资产/make_calc.py
```
