# 08-03 销量下降诊断树

- 版本：v1.0｜最近更新：2026-08-27｜维护人：运营负责人
- 证据等级：诊断方法为 D 级经验

## 1. 模块目的
销售下降时，按「流量 vs 转化」逐层定位根因，避免拍脑袋归因。

## 2. 适用场景
- 销量突然/持续下降时
- 周复盘发现销量异常

## 3. 核心概念
- 核心拆解：销量 = Sessions × Unit Session %。
- 第一问：Sessions 是否下降？（流量问题 vs 转化问题）

## 4. 核心指标
- Sessions、Unit Session %、广告 Impression、自然排名、价格、Review、库存、竞品。

## 5. 决策树
- 如果 销量降 → 查 Sessions 是否降
- 如果 Sessions 降 → 流量问题：广告曝光降 / 自然排名降 / 竞品 / Listing 抑制
- 如果 Sessions 不降 → 转化问题：价格 / Review / Buy Box / Listing
- 如果 广告降自然不降 → 广告问题（08-05）
- 如果 自然降广告不降 → 自然排名问题（08-04）
- 最终确定根因 → 对应模块执行

## 6. 标准操作流程
Step 1：确认销量下降幅度与周期。
Step 2：对比 Sessions 与 Unit Session % 变化。
Step 3：分流到流量问题或转化问题。
Step 4：沿诊断树逐层查（广告/自然/价格/Review/库存/竞品）。
Step 5：确定根因，执行对应 SOP，记录。

## 7. 操作前检查
- 数据周期足够（7 天均值）。

## 8. 操作后检查
- 根因明确、动作已执行。

## 9. 成功标准
- 能定位到具体根因并恢复。

## 10. 失败处理
- 无法定位 → 升级负责人，逐项排查。

## 11. 常见错误
1. 销量降直接怪广告。
2. 不看 Sessions 分流。
3. 多变量混在一起下结论。

## 12. 风险
- 决策：错误归因放大损失。

## 13. 实战案例
背景：周销量降 20%。
数据：Sessions -16%，转化基本平稳。
判断：流量问题。
决策：查广告曝光与自然排名。
结果：发现核心词排名下滑，竞品抢位。
复盘：先分流「流量 vs 转化」。

## 14. Checklist
- [ ] 确认下降幅度
- [ ] 对比 Sessions/转化
- [ ] 分流
- [ ] 逐层排查
- [ ] 定根因执行

## 15. 数据记录模板
字段：日期|ASIN|销量变化|Sessions变化|转化变化|根因|动作|结果

## 16. 复盘方法
每次下降复盘，沉淀诊断经验。
