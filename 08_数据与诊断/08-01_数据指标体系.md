# 08-01 数据指标体系

- 版本：v1.0
- 最近更新：2026-08-27
- 维护人：运营负责人
- 证据等级：见各节标注；所有「正常范围」无通用标准，一律标 D/E

## 1. 模块目的
统一全库指标的定义、公式、数据来源与口径，是 08 诊断树、11 周月报、05 广告、06 转化的共同语言。防止「同一个指标在不同模块算出不同结果」。

## 2. 适用场景
- 任何数据分析、诊断、复盘（08 / 11）
- 广告优化与 ACOS/TACOS 判断（05）
- Listing / 价格 / Review 诊断（04 / 06）
- **不适用**：库存指标（07-01 定义）、利润指标（09-01 定义），本模块只做交叉引用。

## 3. 核心概念

### 3.1 三个数据源体系
| 体系 | 来源 | 主要指标 | 等级 |
|---|---|---|---|
| 业务报告 Business Reports | Seller Central | Sessions、Page Views、Unit Session Percentage、Buy Box 赢得率 | B |
| 广告后台 Advertising Console | Amazon Ads | Impression、Click、CTR、CPC、ACOS、ROAS、广告归因销售 | B |
| 品牌分析 Brand Analytics | 品牌注册后 | 搜索词频率排名、市场篮子、复购、点击份额 | B |

### 3.2 流量漏斗（判断任何问题先定位到「哪一层」）
```
曝光 Impression → 点击 Click → 会话 Session → 订单 Order
   ↑广告位/竞价     ↑CTR(内容)    ↑Listing/价格   ↑CVR(信任)
```
- 广告漏斗：Impression → Click → Order（CTR 看内容吸引力，CVR 看 Listing 承接力）。
- 自然漏斗：Session 是核心起点（自然流量没有「点击」这一层的公开数据，用 Session 近似）。
- 关键区分：**Business Reports 的 Unit Session Percentage 与广告后台的 CVR 是两回事**（见 4.3 / 4.8）。

### 3.3 归因窗口
- 广告点击后转化有滞后，通常观察 7-14 天归因窗口（B，以 Ads Console 当前口径为准）。
- 日维度数据波动大，判断趋势用 7 日均值（D 经验）。

## 4. 核心指标

### 4.1 Sessions（会话）
- 定义：一段时间内独立访问次数；买家在 24 小时内的访问计为 1 次会话【B】
- 公式：无（官方直接给出）
- 数据来源：Business Reports 详情页销售和流量
- 意义：自然流量规模的核心度量，判断「流量有没有问题」
- 正常变化逻辑：随广告投放、排名、季节波动
- 异常表现：突然下降 → 自然排名下降 / 被抑制 / 竞品抢位 / 广告停投
- 局限性：不含广告点击次数，不能直接与广告 Click 相加

### 4.2 Page Views（页面浏览量）
- 定义：页面被浏览总次数，同一会话可多次【B】
- 公式：无
- 数据来源：Business Reports
- 意义：反映 Listing 被看的深度；与 Sessions 的比值近似「人均浏览深度」
- 正常变化逻辑：随流量变化
- 异常表现：Sessions 平稳但 Page Views 下降 → 买家停留变短，可能内容/变体页问题
- 局限性：含变体页跳转，口径较粗

### 4.3 Unit Session Percentage（单位会话率，自然转化率）
- 定义：订购单位数 / 会话数【B】
- 公式：Ordered Units / Sessions × 100%
- 数据来源：Business Reports
- 意义：自然流量的转化效率，判断「流量质量 + Listing 承接力」
- 正常变化逻辑：随价格、Review、季节性、竞争变化
- 异常表现：下降 → 价格 / Review / Listing / 竞争问题（见 08-04）
- 局限性：**不等同于广告 CVR**；分母是 Session 不是 Click，二者不可混用

### 4.4 Impressions（曝光，广告）
- 定义：广告被展示的次数【B】
- 公式：无
- 数据来源：Amazon Ads Console
- 意义：广告获得的流量机会，判断「广告有没有跑出去」
- 正常变化逻辑：随预算、竞价、关键词、类目变化
- 异常表现：骤降 → 预算花不出去 / 竞价过低 / 被否定 / 库存不足（见 10-03）
- 局限性：不含自然流量曝光

### 4.5 Clicks（点击，广告）
- 定义：广告被点击次数【B】
- 公式：无
- 数据来源：Amazon Ads Console
- 意义：广告带来的实际访问，判断「内容有没有吸引力」
- 正常变化逻辑：随曝光与 CTR 变化
- 异常表现：有曝光无点击 → CTR 问题（主图/价格/相关性，见 10-03）
- 局限性：仅广告语境

### 4.6 CTR（点击率）
- 定义：点击量 / 曝光量【B】
- 公式：Clicks / Impressions × 100%
- 数据来源：Amazon Ads Console（也可由 4.4/4.5 复算）
- 意义：广告内容（主图/价格/标题）吸引力
- 正常变化逻辑：主图、价格、评论星级变化时波动
- 异常表现：下降 → 主图/价格竞争力下降 / 广告位变化 / 相关性下降
- 局限性：受广告位（Top of Search vs Rest of Search）影响大，不同位不可直接比较

### 4.7 CPC（单次点击成本）
- 定义：广告花费 / 点击量【B】
- 公式：Spend / Clicks
- 数据来源：Amazon Ads Console
- 意义：单次流量的购买成本，判断「流量贵不贵」
- 正常变化逻辑：随竞价、竞争度、广告位变化
- 异常表现：骤涨 → 竞争加剧 / 竞价上调 / 进入高价广告位（见 10-03）
- 局限性：CPC 低不代表划算，需结合 CVR 看 ACOS

### 4.8 CVR（广告转化率）
- 定义：广告归因订单量 / 广告点击量【B】
- 公式：Ad Orders / Clicks × 100%
- 数据来源：Amazon Ads Console
- 意义：广告点击后的承接转化能力
- 正常变化逻辑：随 Listing、价格、Review、季节变化
- 异常表现：下降 → Listing 承接问题（与 4.3 联动，见 08-04）
- 局限性：**分母是 Click，与 4.3 的 Unit Session Percentage（分母 Session）不同**，不可混用

### 4.9 ACOS
- 定义：广告花费 / 广告归因销售额【B】
- 公式：Spend / Ad Sales × 100%
- 数据来源：Amazon Ads Console
- 意义：广告的直接投入产出，判断「广告亏不亏」
- 正常变化逻辑：随 CPC、CVR、售价变化
- 异常表现：上升 → CPC 涨 / CVR 降（见 08-05 / 10-03）
- 局限性：只看直接归因销售，忽略自然排名增益，需结合 TACOS

### 4.10 ROAS
- 定义：广告归因销售额 / 广告花费【B】
- 公式：Ad Sales / Spend
- 数据来源：Amazon Ads Console
- 意义：每 1 元广告费带来的销售，ACOS 的倒数
- 正常变化逻辑：与 ACOS 反向
- 异常表现：与 ACOS 同一套问题
- 局限性：同上，非官方口径差异需统一

### 4.11 TACOS（非官方指标）
- 定义：广告花费 / 总销售额（广告 + 自然）【D 行业口径，非 Amazon 官方指标】
- 公式：Spend / Total Sales × 100%
- 数据来源：Ads Console（Spend）+ Business Reports / 付款报告（Total Sales）
- 意义：广告对整体生意的成本占比，判断「广告是否在带动自然销售」
- 正常变化逻辑：新品期高、成熟期应下降；若长期不降说明广告依赖过重
- 异常表现：TACOS 上升且自然单占比下降 → 广告依赖症，需检查自然排名（见 05-12）
- 局限性：口径需团队统一（总销售额是否含非广告渠道），否则跨人不可比

### 4.12 Buy Box 赢得率（Featured Offer）
- 定义：详情页获得 Buy Box（Featured Offer）展示的时间占比【B】
- 公式：官方直接给出百分比
- 数据来源：Business Reports / Brand Analytics
- 意义：获得购买按钮的机会，直接影响转化
- 正常变化逻辑：随价格、库存、绩效、跟卖变化
- 异常表现：下降 → 被跟卖 / 价格失去竞争力 / 库存断货（见 06-01 / 10-02）
- 局限性：只反映「是否赢得」，不反映赢得后的转化

## 5. 决策树
- 如果 总销量下降 → 先看 Sessions 是否下降 → 是 → 流量问题（进 4.1 排查）；否 → 转化问题（进 4.3 排查）
- 如果 Sessions 下降 → 看广告 Impression 与自然排名是否同时下降 → 分流到广告诊断（08-05）或 Listing/竞争诊断（08-04）
- 如果 Unit Session Percentage 下降 → 看价格 / Review / Buy Box 赢得率 / 竞品变化（进 08-04）
- 如果 ACOS 上升 → 拆解 CPC 与 CVR：CPC 涨 → 竞争/竞价问题；CVR 降 → Listing 承接问题（进 08-05）
- 如果 TACOS 持续上升且自然占比下降 → 广告依赖，查自然排名与关键词布局（进 05-12）

## 6. 标准操作流程
Step 1：进入 Seller Central → 业务报告 → 详情页销售和流量（按 ASIN / 按日期）。
Step 2：导出 Sessions、Page Views、Unit Session Percentage、Buy Box 赢得率，选统一周期（周/月）。
Step 3：进入 Amazon Ads Console → 导出 Impression、Clicks、Spend、Ad Orders、Ad Sales。
Step 4：将两类数据录入统一数据表（见 15 节）。
Step 5：复算 CTR = Clicks/Impressions、CVR = Orders/Clicks、CPC = Spend/Clicks、ACOS = Spend/Ad Sales、TACOS = Spend/Total Sales。
Step 6：与「自身历史 7 日均值」对比（D 级基准），标记偏离项。
Step 7：偏离项进入对应诊断树（08-03/04/05），并记录。

## 7. 操作前检查
- 时间范围统一（自然周/自然月，不与结算周期混用）。
- 明确本次用的是 Business Reports 的 Unit Session Percentage 还是广告 CVR，不混用。
- 归因窗口统一（广告转化滞后，取同一观察窗口）。
- 确认广告「销售额」口径是广告归因销售（Ad Sales），不是总销售。

## 8. 操作后检查
- CTR/CVR/CPC/ACOS 均可由原始字段复算一致。
- 总销售 = 广告归因销售 + 自然销售，可对账。
- 指标趋势用 7 日均值判断，不用单日值下结论。
- 每个异常项都定位到了具体漏斗层（曝光/点击/会话/订单）。

## 9. 成功标准
- 全库指标口径统一，无「同名不同义」。
- 每周稳定产出指标表，异常能在 24 小时内定位到漏斗层。
- 广告与自然数据能合并出 TACOS，且口径被团队认可（D 级）。

## 10. 失败处理
- 指标对不上 → 优先排查口径（最常错：Unit Session Percentage 与 CVR 混用、TACOS 分母不一致）。
- 数据缺失（某天/某 ASIN）→ 标记缺失，禁止凭空估算后不标注。
- 连续 2 周指标异常 → 升级负责人，进对应诊断树，不复盘不关闭。

## 11. 常见错误（新人高频）
1. 把 Unit Session Percentage 当广告 CVR。
2. TACOS 口径不一致（分母有的含自然、有的不含）。
3. 用第三方估算值当官方数据。
4. 只看单日数据下结论（波动大）。
5. 只看 ACOS 不看 TACOS，误杀有效广告。
6. 混淆 Impression（曝光）与 Session（会话）。
7. 把 Buy Box 赢得率下降误判为转化问题而不查跟卖/库存。

## 12. 风险
- 误判风险：口径错误导致错误广告操作、错误清库、错误定价。
- 传导风险：本模块是 08/05/06 的底座，一旦口径错会系统性放大。

## 13. 实战案例
背景：某 ASIN 周销量下降 20%，需要定位根因。
数据（教学假设值）：
- 本周 Sessions 800（上周 950，-16%）
- Unit Session Percentage 10.5%（上周 11.0%，基本平稳）
- 广告 Impression 12,000（上周 15,000，-20%）、CTR 0.42%（上周 0.40% 平稳）
- 核心词自然排名从第 3 页掉到第 4 页
判断：销量下降主要来自流量下降（Sessions -16%），转化基本没变；广告曝光 -20% 且自然排名下滑，说明是「流量问题」而非「转化问题」。
决策：先不降价、不动 Listing，集中排查流量——广告是否预算被砍/竞价失去竞争力，自然排名为何下滑（竞品上新？Review 被反超？）。
操作：进 08-05 广告诊断 + 02-04 竞品分析，发现竞品上架并大额投放，抢占了核心词位置。
结果：一周后调整竞价与否定，并强化核心词相关度，Sessions 恢复。
复盘：销售下降第一步永远是「Sessions 分流」，先分清流量问题还是转化问题，避免错改 Listing/价格。

## 16. 复盘方法
- 每日：销量 / Sessions / 广告花费快照。
- 每周：各指标 7 日均值趋势，标记偏离 >15% 的项（D 级经验线）。
- 每月：全漏斗健康度 + 广告/自然占比 + TACOS 趋势，输出下月指标目标。
