# 00-03 术语表（v0.1 初始版）

- 说明：本表持续补充。凡涉及官方定义的术语，以 Seller Central 官方帮助页为准并附访问日期；本表为团队内部速查，不含未验证阈值。

## 流量与转化
- Sessions（会话）：一段时间内独立访问次数，买家在 24 小时内的访问被计为一次会话。【B，以官方定义为准，需定期验证】
- Page Views（页面浏览量）：页面被浏览次数，同一会话可多次。【B】
- Unit Session Percentage（单位会话率，近似转化率）：订购量 / 会话数。【B】
- CTR（点击率）：点击量 / 曝光量，广告语境常用。【B】
- CVR（转化率）：订单量 / 点击量（或会话数，口径需在 08-01 统一）。【B/D】
- CPC（单次点击成本）：广告花费 / 点击量。【B】

## 广告
- ACOS：广告花费 / 广告销售额。【B】
- ROAS：广告销售额 / 广告花费。【B】
- TACOS：广告花费 / 总销售额（广告 + 自然），口径可自定。【D 经验口径】
- Placement（广告位）：广告展示位置，如 Top of Search、Product Pages、Rest of Search。【B】
- 否定关键词 / 否定商品：阻止广告在指定词 / 商品位展示。【B】
- 自动广告 / 手动广告：系统自动匹配 vs 手动选择投放目标。【B】
- Deal：促销活动，常见 LD（Lightning Deal）、7DD（7-Day Deal）、DOTD（Deal of the Day）。【A/B，资格与费用需定期验证】

## 账户与绩效
- ODR（订单缺陷率）：负面反馈 + 索赔 + 拒付 / 订单数。【A，阈值需定期验证】
- VTR（有效追踪率）：有效追踪的订单占比。【A，阈值需定期验证】
- IPI（库存绩效指数）：库存健康度指标，影响仓储与补货限制。【A，阈值需定期验证】
- Buy Box（购买按钮）：商品详情页主购买按钮，归属机制官方未完全公开。【B/A 部分公开】

## 库存与物流
- ASIN：Amazon 商品唯一标识。【B】
- SKU：卖家自定义商品编码。【B】
- FNSKU：FBA 商品条形码标识。【B】
- FBA：由 Amazon 履行配送。【A】
- FBM：卖家自配送。【A】
- 可售库存（Fulfillable）/ Reserved / Inbound：FBA 库存三种状态。【B】
- 头程物流：从供应商/国内仓到 FBA 仓的运输段。【D 行业术语】
- Lead Time（补货周期）：下单到可售的总时间，含生产 + 运输 + 入仓。【D】
- 安全库存：应对波动预留的库存量。【D】
- 补货点：触发补货的库存水位。【D】
- 断货日：按当前销量预计库存耗尽日期。【D 计算】

## 利润
- 毛利 / 贡献利润 / 运营利润 / 净利润：不同费用扣除口径，定义与公式见 09-01。【D 口径，团队统一】
