# 00-08 使用指南与交付说明

- 版本：v1.0｜更新：2026-08-27

## 1. 这套 SOP 是什么
一套 Amazon 全流程运营知识库，可执行、可验证、带证据等级。包含：82 份业务 SOP + 7 份总纲 + 1 份反向测试报告 + 1 份 Level0 入门 + 1 份通用案例实操手册 + 3 个 Excel 计算器。

## 2. 按角色找入口
- 新人：先读 12-00 Level0 入门 → 12-01 学习路线 → 照着「从0到1实操手册_通用案例」做一遍
- 日常运营：11-01 每日清单 + 运营工作日志
- 出问题：10 风控异常（急救）→ 08 诊断树
- 做广告：05-01 总览 → 05-02/05-03/05-04 → 05-11 优化循环
- 算利润：09-01 利润口径 + C01 计算器
- 管库存：07-02 补货 + C03 计算器
- 负责人：00-02 证据等级 + 01-06 政策追踪 + 00-07 反向测试

## 3. 三个 Excel 计算器（配套文件，位于 99_支撑资产/计算器/）
| 文件 | 用途 |
|---|---|
| C01_利润计算器.xlsx | 输入费用项 → 四层利润 + 盈亏平衡 ACOS |
| C03_库存补货计算器.xlsx | 输入销量/时间 → 补货点 + 预计断货日 |
| C04_广告ACOS_TACOS计算器.xlsx | 输入广告/销售 → ACOS/ROAS/TACOS + 盈亏判断 |
说明：默认值已填教学示例值（售价 $21.99、盈亏平衡 ACOS 28.6%），改黄色单元格即自动重算。
