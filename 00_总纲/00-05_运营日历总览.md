# 00-05 运营日历总览

- 版本：v1.0
- 最近更新：2026-08-27
- 说明：本文件为总览，执行细则见 11-01 ~ 11-05。

## 每日（约 30-60 分钟）
1. 销售与订单：总销量、各 ASIN 销量 vs 昨日 / 7 日均值，记录异常。
2. 广告：花费、ACOS、曝光、点击是否有骤变（对比 7 日均值）。
3. 库存：可售库存 vs 补货点，检查断货预警。
4. 异常：账户通知、绩效指标、Buy Box、差评、退货是否异常。
5. VOC：新评论、客户问题（含 QA）。
6. 竞品：竞品价格 / 排名 / 促销是否突变。

## 每周
1. 广告复盘：搜索词报告、否定、预算 / 竞价调整（见 05-11）。
2. 关键词排名：核心词自然排名变化。
3. 竞品：周维度价格 / 评论 / 排名对比。
4. Deal / 秒杀 / Coupon：报名与效果。
5. 库存：补货计划更新、在途跟进（见 07-02）。
6. Review：周增量、评分趋势。
7. 数据记录：填写周报模板（见 08-07）。

## 每月
1. 利润：全口径利润核算（见 09-01 / 09-02）。
2. 产品 / 类目：品类趋势、市场变化（见 02-01）。
3. 广告：月度 ACOS / TACOS 总结与下月预算。
4. SKU：SKU 健康度、畅销 / 滞销盘点。
5. 库存周转：周转率、仓储费、IPI（见 07-04）。
6. 预算：下月预算与目标。

## 每季度
1. 政策校验：所有 A/B 级内容逐项复核，刷新访问日期（见 00-02）。
2. 产品线：产品生命周期审视（见 03-08）。
3. 供应商：价格 / 交期 / 质量复盘。
4. 团队：培训考核、SOP 更新。
